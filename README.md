# 🚗 YOLO Object Detection, Tracking & Line-Crossing Counting

## 📌 Project Overview

This project uses **YOLO11** for real-time object detection and tracking in a video. The system detects vehicles and other selected objects, assigns a unique tracking ID to each detected object, and counts the objects when they cross a predefined red line.

The project demonstrates how object detection can be combined with **object tracking and line-crossing logic** to perform vehicle counting from video footage.

---

## 🎯 Objectives

* Detect objects in a video using YOLO11.
* Track detected objects across multiple frames.
* Assign a unique ID to each tracked object.
* Draw bounding boxes around detected objects.
* Display the center point of each object.
* Detect when an object crosses a predefined line.
* Count each object only once.
* Display class-wise object counts on the video.

## 🧠 YOLO Model

The project uses:

```python

model = YOLO("yolo11l.pt")
```

YOLO11 is used to detect objects in each video frame.

The model provides:

* Bounding box coordinates
* Object class
* Confidence score
* Tracking ID

## 🚘 Object Classes

The project filters the YOLO classes using:

```python
classes=[1, 2, 3, 5, 6, 7]
```

According to the COCO class labels:

| Class ID | Object     |
| -------: | ---------- |
|        1 | Bicycle    |
|        2 | Car        |
|        3 | Motorcycle |
|        5 | Bus        |
|        6 | Train      |
|        7 | Truck      |

This allows the project to focus mainly on **vehicles and transportation-related objects** instead of detecting all available COCO classes.

## 📍 Line-Crossing Detection

A horizontal red line is created at:

```python
line_y_red = 430
```

The center point of every detected object is calculated:

```python
cx = (x1 + x2) // 2
cy = (y1 + y2) // 2
```

The program then checks whether the object's center point has passed the red line:

```python
if cy > line_y_red and track_id not in crossed_ids:
    crossed_ids.add(track_id)
    class_counts[class_name] += 1
```

The `crossed_ids` set ensures that the same object is **not counted multiple times** after crossing the line.

## 🔍 Key Concepts Demonstrated

### Object Detection

YOLO identifies objects and returns their bounding boxes, classes, and confidence scores.

### Object Tracking

YOLO tracking maintains an ID for an object across consecutive frames.

### Center Point Calculation

The center of each bounding box is calculated to determine its position relative to the counting line.

### Line-Crossing Counting

When the center point passes the predefined line, the object is counted.

### Duplicate Prevention

A Python `set` is used to store IDs that have already crossed the line:

```python
crossed_ids = set()
```

This prevents the same vehicle from being counted more than once.
